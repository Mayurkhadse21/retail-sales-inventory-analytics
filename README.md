### End-to-End Business Intelligence Solution using MySQL, SQL & Power BI

---

## 📌 Project Overview

This project demonstrates an end-to-end Business Intelligence solution for a retail company. The objective was to transform raw sales and inventory data into actionable business insights using SQL for data preparation and Power BI for interactive reporting.

The project follows a complete analytics workflow including data cleaning, exploratory analysis, business KPI development, data modeling, DAX calculations, and executive dashboard design.

---

## 🎯 Business Objectives

- Monitor sales performance across stores
- Analyze product category performance
- Evaluate business profitability
- Track inventory value
- Identify top-performing stores and products
- Enable executive-level decision making
